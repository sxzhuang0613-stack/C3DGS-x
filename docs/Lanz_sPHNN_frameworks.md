## 1. Lanz：分离式吸引子

### 1.1 理论

**问题** [原文]：递归吸引子网络存在“稳定 ↔ 灵活”的矛盾，即记忆容易保持，却难以快速写入或关闭。

**回路** [原文]：
- hΔK（30 个）与 PFG（18 个）在扇形体上成环状互相兴奋；
- 一个全局抑制单元同时抑制两者；
- 罗盘输入只进入 PFG；
- PFG 到 hΔK 的兴奋慢，抑制快。

**动力学** [原文式 1–4]（下标 K=hΔK，P=PFG，I=抑制单元）：

$$
\begin{aligned}
\dot u_K &= -\alpha u_K + \mathrm{exc}\,W_{KP}U_P - U_I + I_K\\
\dot u_P &= -\alpha u_P + \mathrm{exc}\,W_{PK}U_K - U_I + I_P\\
\dot u_I &= -\alpha u_I + \mathrm{inh}\,(\mathbf 1^\top U_K+\mathbf 1^\top U_P)\\
U'' &= -(a+b)\,U' + ab\,\big(F(u)-U\big)
\end{aligned}
$$

- $F$ 为截断到 $[0,1]$ 的线性函数，$\alpha=10$；
- $W$ 是圆周上的高斯连接，$\sigma=0.25$；
- 快突触 $a=4.63$，慢突触 $a=0.64$，$b=25$，只有 PFG 使用慢突触。

**三个结论**：
1. **慢兴奋使持续时间可调** [原文 Fig. 3]：快兴奋时，持续时间只在很窄的参数带内是有限且可调的；慢兴奋时，可调区域很宽。
   - 线性化解释 [推导]：$\tau \approx 1/\big(a(1-W_{\text{eff}})\big)$，慢突触把可调带宽放大约 $1/a$ 倍。
2. **两种工作区** [代码 + 原文]：
   - 慢衰减区：与实验数据匹配，Fig. 3i 已排除永不衰减的仿真；
   - 永不衰减区：由截断饱和引起，是双稳态。
3. **门控** [原文 Fig. 5]：
   - hΔK 被抑制时，PFG 以低幅活动峰跟随罗盘输入；
   - 解除抑制时，递归回路接通，把当前输入锁存下来；
   - 解耦之所以成立，依赖截断非线性。

### 1.2 框架流程 [代码]

```text
连接矩阵（高斯或连接组） ─► 设定 exc/inh、快慢突触、外部输入 I(t)、门控时序
        ─► 显式 Euler 积分（dt = 1 ms）：每步先更新突触 (U', U)，再更新率 r = clip(·)
        ─► 分析：活动峰位置与宽度；输入撤去后拟合指数衰减，得到 τ；扫描 (exc, inh)
```

这是计算神经科学仿真，没有可学习参数。

## 2. sPHNN：稳定的 port-Hamiltonian 神经网络

### 2.1 理论

**系统形式** [原文式 3–4]：

$$
\dot x=\big[J(x)-R(x)\big]\nabla H(x)+G(x)\,u,\qquad
\dot H=-\nabla H^\top R\,\nabla H+\nabla H^\top G u
$$

其中 $J=-J^\top$，$R=R^\top\succeq0$。

**定理 3.1** [原文]：设 $u=0$，$H$ 凸，且在 $x^*$ 处有严格极小（Hessian 正定）。
- 则所有轨迹有界，$x^*$ Lyapunov 稳定；
- 若 $R\succ0$，则 $x^*$ 全局渐近稳定，且平衡点唯一。

**有输入时** [原文]：只有无源性 $\dot H\le\nabla H^\top Gu$，没有有界性保证。

**局限** [原文]：只能建模全局稳定的系统；多稳态留作未来工作。

### 2.2 框架流程 [代码]

```text
H = LyapunovNN(FICNN)：f(z) − f(z₀) − ⟨z − z₀, ∇f(z₀)⟩      # 凸，且极小点固定在 x*
J：反对称（辛矩阵 / 可学习常数 / 依赖状态）
R = LLᵀ：所有实验都用全局正定的常数矩阵
G：常数矩阵
        ─► ẋ = (J − R)∇H + G·u(t)，其中 u(t) 是已知数据，经插值后输入
        ─► diffrax Tsit5 积分 ─► 导数拟合和/或轨迹拟合（MSE，Adam）
        ─► 验证：极小点处 Hessian 正定，且 R 正定 ⇒ 全局渐近稳定
```

**潜空间用法** [代码，增材制造实验]：
- 用 POD 编码状态场和激励场；
- 平移潜坐标，使平衡点落在原点；
- 无激励编码为零输入；
- J 为可学习的常数反对称矩阵，**潜状态没有 (q, p) 划分**。

## 3. 融合思路

### 3.1 主次关系

- **sPHNN 为主**：提供动力学形式、训练框架和稳定性保证。
- **Lanz 为辅**：提供分群体拓扑、快慢时间尺度和门控式递归，作为结构先验嵌入。
- **不继承的部分**：
  - 环形吸引子、永不衰减的持续性（与凸 H 互斥）；
  - 由截断实现的解除抑制（线性 PH 中加性输入无法解耦）；
  - “慢兴奋带来稳健性”（sPHNN 中持续时间由 R 直接决定，不存在相消问题，因此不作为贡献点）。

### 3.2 理论依据

**T1：Lanz 的慢衰减区属于 sPHNN 的模型类** [推导]

任何渐近稳定的线性系统 $\dot x=Ax+Bu$ 都可以写成线性 PH 系统：
- 解 Lyapunov 方程 $A^\top Q+QA=-I$，得到 $Q\succ0$；
- 取 $H=\tfrac12x^\top Qx$，$J-R=AQ^{-1}$；
- 则 $R=\tfrac12Q^{-2}\succ0$，$G=B$。

因此，在激活神经元集合不变的区段内，Lanz 的分群体网络就是一个 R 正定的 sPHNN。

两点限制：
- 截断使整个系统成为分段线性系统，跨区段的公共 Lyapunov 函数不保证存在；
- 变换到 PH 坐标后，J 和 R 一般是稠密矩阵，连接组的结构只保留在 $G=B$ 中，即“输入只进入 PFG 对应的分量”。

**T2：门控不破坏稳定性** [推导]

取 $R(t)=R_{\text{base}}+R_c(t)$，其中 $R_{\text{base}}\succ0$、$R_c(t)\succeq0$，且 $H$ 不随时间变化。则当 $u=0$ 时：

$$
\dot H\le-\lambda_{\min}(R_{\text{base}})\,\|\nabla H\|^2
$$

由于 $H$ 凸且径向无界，可推出 $x\to0$。也就是说，任意随时间变化的门控都保持全局渐近稳定。有输入时仍只有无源性。

**T3：门控式写入与锁存** [推导]

门控项取 $R_c=c\,g(t)\,B_c^\top B_c$，其中 $B_c=[\Pi,\ -I]$。
- $R_c$ 半正定，因此是合法的耗散项；
- 它把 $\partial H/\partial k$ 拉向 $\Pi\,\partial H/\partial m$；若两个方向的曲率相同，就是 $k$ 跟随 $\Pi m$；
- $g=1$：写入；$g=0$：$k$ 只受 $R_{\text{base}}$ 中很小的 $k$ 块耗散，缓慢衰减，即有限时长的锁存。

注意两点：
- 这对应 Lanz 的**直接门控**（Fig. 5b，调制递归强度）的计算效果，不是解除抑制的生理实现；
- 耦合是对称的，$m$ 也会被拉向 $k$。

### 3.3 框架 [设想]

**状态**：$x=[m,k]$
- $m$：运动状态，进入解码器；
- $k$：运动上下文，不进入解码器，只通过 $H$ 的交叉项和门控耦合影响 $m$。

| 组件 | 设计 | 对应 Lanz 的机制 |
|---|---|---|
| $H$ | FICNN 加归一化，极小点在 $0$，对应 Stage-1 规范构型 | — |
| $J$ | 可学习的常数反对称矩阵（与 sPHNN 潜空间实验一致） | — |
| $R_{\text{base}}$ | 全局正定；$m$ 块耗散大（快），$k$ 块耗散小（慢） | 快慢时间尺度 |
| $R_c(t)$ | $c\,g(t)\,B_c^\top B_c$ | 门控式递归：写入 / 锁存 |
| $G$ | $[G_m;\ 0]$，输入只进入 $m$ | 输入只进入 PFG |
| $u(t)$ | **已知信号，不含可学习参数**，例如 $(\cos2\pi t,\sin2\pi t)$ 或影像测得的曲线 | — |
| $g(t)$ | 少参数的平滑函数，例如 sigmoid 作用于少数谐波 | 门控时序 |

```text
x(0) = 0 ─► 积分 ẋ = (J − R(t))∇H + G·u(t)，从 0 到 t ─► m(t)
m(t) ─► D(m, e_j) − D(0, e_j) ─► 控制点 j 的 {Δμ, Δlog s, Δ旋转（轴角左乘）, Δ强度}
     ─► MLS 传播到各高斯 ─► 切片渲染 ─► 渲染损失 + 体积 / 平滑 / 折叠 / 锚点正则
```

- $e_j$ 是控制点 $j$ 在规范位置的嵌入。
- 训练只能用轨迹拟合（没有导数数据），由现有 Stage-2 中“从 0 积分到目标时刻”的流程承载。

### 3.4 预期收益与检验

| 收益 | 来源 | 检验方法 |
|---|---|---|
| 演化有界；无驱动时回到规范态 | T2 | 外推超出一个周期；测量闭合误差和漂移 |
| 全属性协调演化；$m=0$ 时精确还原 Stage-1 | 平衡点在原点，且 $D(0)$ 归零 | 检查规范态复现；检查运动分支是否在补偿静态误差 |
| 稀疏观测下更稳健 | sPHNN 的实验结论（心脏场景尚未验证） | 留出部分时相或切片进行评估 |
| 运动上下文与模式切换 | T3 | 消融；检查 $g(t)$ 是否与 ES 时刻对齐 |

**消融链**：时间条件化基线 → 潜空间 NODE → sPHNN → sPHNN 加 Lanz 结构。

### 3.5 待定问题

1. $u(t)$ 用哪种已知信号。它决定动力学需要解释的内容，也是归纳偏置是否有效的关键。
2. $g(t)$ 是可学习的少参数函数，还是由 ES 时刻固定。
3. 强度是否演化。若演化，需要修改 `Motion.py` 中 `render` 的 `colors=base_colors`。
4. 潜维度 $d_m$、$d_k$，以及解码器采用线性模态还是非线性形式。
